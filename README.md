# Spiceworks Ticketing System Lab
Documentation of Ticketing System using Spiceworks.
### 
![Logo](Logo.png)

## Project Overview
This project documents how Ticketing System works in a real world scenario using Spiceworks.

## Lab Environment
- Spiceworks web platform 

## Ticket Workflow Testing 
- Simulated Ticket Creation (Subject, Issue description, Category, Prioriy Attachments). 
- Objective : Understand how tickets are created and categorized

### Ticket Creation
![Ticket Creation](Ticket%20creation.png)
  
- Ticket Closure Checklist (Confirm resolution with the user, Update ticket notes, Close the ticket with proper resolution code.)
- Objective : Ensure a ticket is properly resolved and documented
  
### Closing Ticket
![Closing Ticket](Closing%20Ticket.png)
  
- Escalation (When to escalate, To which team(e.g., Administrator), What info should be included when escalating
- Objectives : Understand when and how to escalate a ticket.
  
### Escalating Ticket
![Escalating Ticket](Escalating%20Ticket.png) 

## Features Explored
- User management
- Internal note 
- Ticket assignment
- Email notifications
- Reports dashboard
- Changed status: Open → In Progress → Closed
- Added comments and resolution notes.
  
## Lessons Learned
- How ticket lifecycle work (Process Flow)
- Importance of documentation in IT support
- Basic troubleshooting of services
- Proper approach for resolving a problemS
- How to properly log a ticket 
- Key components of a ticketing system
- Priority Level (Determining Urgency)
